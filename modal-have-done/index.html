01 / UNDERSTAND

先搞懂
情态动词 + have done 怎么表达过去？

“情态动词 + have done”可以用来回看过去，表达“本来应该”“本来可以”或者“如果当时……就会……”等不同含义。

点击任意卡片，看看一个真实工作场景里的用法。

三个结构都在“回看过去”，但关注点不同：

SHOULD本来应该做，但没做
COULD本来可以做，但没选
WOULD如果条件不同，就会……

情态动词 + have done

SHOULD HAVE DONE本来应该做，但没做

WOULD HAVE DONE如果当时……，就会……
